# Tag

Small labels on menu cards (`pt-tag`) and selectable flavor chips (`pt-chip`).

**Consumer provides:** a short ALL-CAPS-rendered label (write it in sentence case; CSS uppercases it), an optional `pt-icon`, and a colour modifier.

- `pt-tag--chile` + flame icon = spicy (always pair the word with the icon — never colour alone).
- `pt-tag--queso` + star = fan favorite / best seller. Max one per card.
- `pt-tag--nopal` = fresh / veggie. `pt-tag--jamaica` = drinks only.
- `pt-chip` is a toggle button: set `aria-pressed`. Use for agua fresca flavors and taco meat choice.
